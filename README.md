# 📚 Study Tracker v1.0

A Python-based Study Tracker that helps students manage subjects, track study hours, set goals, view progress statistics, and visualize study data using charts.

---

## 🚀 Features

### Subject Management

* Add subjects
* Delete subjects
* View all subjects

### Study Hours Tracking

* Record study hours for each subject
* Automatically save data

### Progress Levels

Based on study hours:

* Beginner (0–4 hours)
* Intermediate (5–9 hours)
* Advanced (10+ hours)

### Statistics

* Total subjects
* Total study hours
* Most studied subject
* Average hours per subject

### Weekly Report

* Total study hours
* Subject-wise study hours
* Top studied subject

### Study Goals

* Set study-hour goals
* Track goal progress
* Goal achievement notification

### Data Persistence

* Saves subjects and study hours in `subjects.txt`
* Saves goals in `goal.txt`
* Data remains available after restarting the program

### Charts

* Visualize study hours using Matplotlib bar charts
* Subjects are sorted by highest study hours first

## ▶ How To Run

### 1. Install Python

Make sure Python 3 is installed.

Check:

```bash
python --version
```

### 2. Install Matplotlib

```bash
pip install matplotlib
```

### 3. Run the Project

```bash
python study_tracker.py
```
